Project Summary

Public Wi-Fi Safety is an educational web application built to help users evaluate security risks on public or open wireless networks using simulated parameters. People frequently connect to free Wi-Fi hotspots at stations, cafes, and public places without checking encryption strength, duplicate SSID indicators, VPN protection, or sharing settings. This project calculates a clear safety score, highlights potential risks, and provides safe-use guidance without scanning or attacking any live public or institutional network.

Problem Statement & Objectives

Problem Statement: Public Wi-Fi networks often lack strong encryption or rely on shared passwords, exposing user traffic to eavesdropping, rogue access points, or unauthorized access through enabled file sharing. Beginners often do not know how to judge whether a hotspot is safe for logins or payments.

Objectives

  1. Design a clean interface to enter simulated Wi-Fi settings and view a safety score.
  2. Build scoring logic based on encryption type, VPN status, HTTPS/firewall flags, and sharing settings.
  3. Demonstrate core networking and security ideas including wireless encryption, Evil Twin risks, and OS sharing hygiene.
  4. Test sample Wi-Fi cases covering high risk, protected networks, and duplicate SSIDs.
  5. Document safe Wi-Fi habits, system design, and submission details.

Scope, Concepts, Tools & System Design

Scope & Limitations: Covers simulated parameter checks and safety advice. Does not capture live packets, scan external networks, or launch attacks.

Concepts Used: Wireless encryption (Open, WEP, WPA2, WPA3), Evil Twin / MITM awareness, VPN and HTTPS protection, and OS file-sharing/firewall hygiene.

Tools & Technologies: VS Code, HTML5, CSS3, JavaScript, and a modern web browser.

System Design: Input Form & Presets -> Validation & Score Calculation -> Risk Verdict & Recommendations.
